# 1. 基础项目结构
my-jekyll-site/
```
├── _config.yml       # 站点配置
├── _layouts/         # 布局模板
│   ├── default.html  # 默认布局
│   ├── post.html     # 文章布局
│   └── page.html     # 页面布局
├── _includes/        # 可重用组件
│   ├── header.html
│   ├── footer.html
│   └── nav.html
├── _posts/           # 博客文章
├── _sass/            # Sass部分文件
├── assets/
│   ├── css/          # 主样式文件
│   └── js/           # JavaScript文件
├── index.html        # 首页
└── about.md          # 关于页面
```
核心工作流程
1. ​​解析阶段​​：读取_config.yml获取全局配置
2. 内容收集​​：扫描_posts、_pages等目录收集内容
3. 模板处理​​：通过Liquid模板引擎处理布局和包含文件
4. 静态生成​​：将Markdown转换为HTML并应用布局
5. 输出结果​​：生成_site目录包含完整静态网站

# 2. 各个模块细节
* 所有文章都在`_posts`文件夹中
* 文件命名都是 `YYYY-MM-DD-标题.md`的格式
